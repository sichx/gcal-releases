# GCal releases

Downloads for GCal, a native macOS client for Google Calendar.

**[Download the latest GCal.dmg](https://github.com/sichx/gcal-releases/releases/latest/download/GCal.dmg)**

Open the disk image and drag GCal to Applications. Requires macOS 15 or later. Every build is signed with Developer ID and notarized by Apple.

All versions are listed under [Releases](https://github.com/sichx/gcal-releases/releases).
